# VoiceLaw RP

Поиск по кодексам голосом — офлайн, без интернета.

## Скачать

Готовый архив лежит в разделе **[Releases](../../releases/latest)** — файл
`voice-law-rp-1.0.0-win64.zip` (около 310 МБ).

## Как запустить

1. Распакуйте архив в любую папку.
2. Запустите `VoiceLawRP\VoiceLawRP.exe`.

Устанавливать ничего не нужно: среда выполнения, модели и кодексы уже внутри.
Нужна Windows 10 или 11, 64 бита.

## Как пользоваться

- Нажмите **F11** (или удерживайте кнопку записи), скажите фразу и отпустите.
- Спрашивать можно по смыслу: «у полицейского неправильный значок».
- Или по номеру: «статья 40», «шесть точка один», «двенадцать восемь», «глава 4».

## Что внутри

- 6 кодексов: LSPD, Дорожный, Процессуальный, Уголовный, Административный, SASPA
- 502 статьи и готовый поисковый индекс — индексировать не нужно
- Распознавание речи и поиск работают на компьютере, интернет не требуется

## Исходный код

Программа распространяется только в виде готовой сборки. Исходный код не публикуется.

## Проверка версии

```
VoiceLawRP.exe --check
```
